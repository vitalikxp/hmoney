# ХаниМани — карта функций приложения (анализ бандла демо, 2026-09)

**Источник**: https://demo.hmbee.ru/app/ (SPA, Vue). Доступ: срез HTML + JS-чанки через curl
(playwright к демо не подключился — сетевая блокировка), русский UI-текст извлечён из бандлов.
**Дата обращения**: 2026-09-11.

## Карта страниц приложения (по именам чанков)

### Разделы навигации (desktop)
`Счета и Конверты` → `Календарь` → `Список` → `Отчёты` (+ `Настройки`, `Импорт`, `Партнёрская программа`)

### Транзакции (popover создания/редактирования)
- Natural language: `5*250 яблоки (100 в скобках не учтётся)` — «Описание должно включать сумму»
- Назначение: «На счёт» / «На конверт»; типы: доход / расход / «перевод» (описание перевода)
- «План» / «Планировать», «Планируемая сумма с описанием», «Разница между Фактом и Планом»
- «двойной» (двойная запись), «запланировано»
- «Один из связанных счетов был удалён» — обработка удаления счёта

### Регулярные транзакции (form_repeat_options)
- «Не повторять» / «Всегда» / «До даты» («Повторять до:», «Выберите дату окончания повторений»)
- Периодичности (из основного бандла): Каждый день / Каждую неделю / Каждый месяц / Каждый год /
  Каждые 2–6 дней, Каждые 2–4 недели, Каждые 2–4 месяца, Каждые 1.5 месяца, Каждые полгода,
  По будням, По выходным
- При редактировании повторяющейся: «Только эту» / «Перенести эту и будущие», «Прошлые транзакции будут не тронуты»

### Переводы
- Два типа: «между счетами» и «между конвертами»

### Импорт CSV (inside-pages-import)
- «Импорт операций из CSV»: загрузка файла, «Выберите колонки для импорта» (Дата, Сумма
  «доходы +, расходы –», Описание, Категория), «Выберите счёт», «Кодировка»
- После импорта: «Импорт завершён. Все транзакции помечены тэгом #импорт… в описании.
  По этому тэгу их можно будет найти в Списке»

### Календарь
- Отображение дня: «кратко» / «подробно»
- Фильтры: «Все категории / Все конверты / Все счета / Все типы», «неподтверждённые»,
  «Поиск по описанию (ИЛИ)», «сбросить»
- Номер недели дня («day_week_number»), tooltip транзакции, «Перенести ещё и будущие транзакции?»
- Подсказка: «Щёлкните по дню календаря, чтобы внести доход/расход/перевод»

### Отчёты (reports-*)
- **period** (за период): Доходы/Расходы/Разница, «Всего денег», «/мес» (в среднем в месяц),
  «от доходов» (расходы как % от доходов); гранулярность: «По месяцам» / «По годам» /
  «Свой период» / «С начала учёта»; «Прошлые / Будущие» (факт vs план)
- **period_categories / period_accounts**: фильтры «включить/исключить категории/счета»
- **categories_stats (treemap)**: статистика по категориям в виде treemap
- **compare_periods**: сравнение периодов
- **net_worth**: «Всего денег» — общее состояние
- **period_by_months_chart**: график по месяцам

### Счета (accounts-*)
- Тип счёта, «Кредитный лимит», «доступно» (для кредиток)
- «Категория счёта» + «Сменить имя категории», «Вы можете отсортировать категории на свой вкус»,
  «Показывать категорию в списке счетов» — категории счетов настраиваемые и сортируемые
- «Изменить порядок» (сортировка счетов), «Импортировать из CSV» (и для счетов)
- «editable_balance»: «Счёт не участвует в бюджете» — ручное редактирование баланса
- «account_forecast»: «Сумма и Будущий Баланс», «Планы» — прогноз баланса счёта по планам
- «Рез.» — зарезервированная сумма в списке счетов (accounts-stats)
- «Не удаляйте последний Счёт», «Вы уверены, что хотите удалить «{0}»?»
- «Размер ХаниМани изменится на …» — влияние изменения счёта на ХаниМани

### Виртуальные счета (virtuals-*)
- «virtuals-goal_info»: «Нужно накопить», «Накоплено», «Осталось», «Потрачено»,
  «Для достижения цели нужно откладывать X в месяц/неделю» — расчёт темпа накопления
- `form_account_virtual` — виртуальный счёт как назначение транзакции

### Настройки (settings-*)
- «Настройки», «Подписка», «Сброс и Удаление аккаунта» (danger zone)
- Из основного бандла: «Основная валюта», «Начало недели» (Понедельник/Воскресенье)

### Мобильная версия (mobile-*)
- Отдельный UI: `mobile-pages-accounts`, `mobile-pages-envelopes`, «Внести», «Главная»,
  «Мой профиль», «Продлить доступ», offline-подсказка «А интернета-то, похоже, и нет :(»

### Прочее
- `currencies_calculator`: «Курсы валют», «Курс к {0}», «Основная валюта» — мультивалютность
- `date_changer`: навигация периодами (По месяцам/По годам/С начала учёта/назад на N)
- `totals_stats` (Alt+Z): «не потрачено» / «перепотрачено»
- PWA: `offline_bar` («ОФФЛАЙН»), «Доступна новая_version!» (service worker update),
  `ios_prompt` (установка на iOS)
- `forecast_modal`, `planning_modal` (onboarding-пример планирования: «Примеры расчётов»,
  «Сейчас в Резервах», «оптимальная сумма», «недостаток/излишек»)
- `categories_editor` — редактор категорий; «Категория / подкатегория», «Подкатегории»
- `friends` — партнёрская программа («Зарабатывайте реальные деньги, рекомендуя ХаниМани»)
- «Скрытые» (фильтр), «показать ещё» (ленивая подгрузка), «Начало недели», «По месяцам»

## Выводы для ТЗ

1. Регулярные транзакции — богатая периодичность + правило обновления («эту/эту и будущие»)
2. Импорт CSV — отдельная страница, тэг #импорт в Списке
3. Отчёты — 4 типа: период (с фильтрами), категории (treemap), сравнение периодов, Net Worth;
   гранулярность месяц/год/свой период/с начала учёта
4. Будущий баланс счёта (forecast) — окно счёта показывает «Планы» и будущую сумму
5. Категории счетов — настраиваемые, сортируемые
6. Мультивалютность с калькулятором — post-MVP
7. Мобильный UI — отдельные страницы, не только адаптив
8. Семейный доступ (несколько пользователей одновременно) — из отзывов, пост-MVP
